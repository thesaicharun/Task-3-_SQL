# Task 3: SQL for Data Analysis

## 📌 Overview

This project is part of the **Data Analyst Internship** and focuses on using SQL to extract, manipulate, and analyze structured data.

For this task, an **E-Commerce dataset** was used to perform different SQL operations including filtering, sorting, grouping, joins, subqueries, aggregate functions, views, and query optimization.

---

## 🎯 Objective

The objective of this task is to use SQL queries to extract useful insights from an E-Commerce database and understand how structured data can be analyzed efficiently.

---

## 🛠️ Tools & Technologies

- SQL
- MySQL / PostgreSQL / SQLite
- E-Commerce Dataset
- GitHub

---

## 📂 Dataset

**Dataset:** E-Commerce SQL Database

The dataset contains structured e-commerce-related information that can be queried to analyze customers, orders, products, sales, and revenue.

---

## 🔍 SQL Concepts Covered

The following SQL concepts were implemented in this task:

### 1. SELECT
Used to retrieve data from database tables.

### 2. WHERE
Used to filter records based on specific conditions.

### 3. ORDER BY
Used to sort query results in ascending or descending order.

### 4. GROUP BY
Used to group records based on specific columns and perform aggregate calculations.

### 5. Aggregate Functions
The following functions were used:

- `SUM()`
- `AVG()`
- `COUNT()`
- `MIN()`
- `MAX()`

### 6. Joins
Different types of joins were explored:

- INNER JOIN
- LEFT JOIN
- RIGHT JOIN

Joins were used to combine information from multiple related tables.

### 7. Subqueries
Subqueries were used to perform calculations or filtering using the result of another SQL query.

### 8. Views
SQL views were created to simplify repeated analysis and provide reusable query results.

### 9. NULL Value Handling
NULL values were handled using appropriate SQL techniques such as:

- `IS NULL`
- `IS NOT NULL`
- `COALESCE()`

### 10. Query Optimization
Indexes and efficient query structures were considered to improve SQL query performance.

## 📊 Analysis Performed

The SQL queries were used to analyze:

- Total revenue
- Average revenue
- Customer information
- Order information
- Product information
- Sales performance
- Customer/order relationships
- Aggregated business metrics
